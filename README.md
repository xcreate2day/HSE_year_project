# Тема: Прогнозирование вероятности задержки авиарейса по входным данным с использованием методов машинного обучения
# План работы на год
# До 6 октября: фиксируем тему и план работы, создаём репозиторий на GitHub.
# До 7 ноября: собираем данные о рейса, проводим EDA (доля задержек, сезонность, взаимосвязи признаков и тд), делаем визуализации и выводы.

# 10–15 января: промежуточная защита: итоги семестра и планы на второй семестр.
# До 15 марта: улучшаем модель за счёт более сложных алгоритмов, новых признаков (погода, загруженность, история рейса), очистки и расширения данных, калибровки вероятностей.
# До 5 мая: применяем нейронные сети и сравниваем их с ML-подходами.
# Май – начало июня: настраиваем MLflow и воспроизводимость экспериментов, логируем лучшую модель, анализируем ошибки и устойчивость.
# 13–20 июня: итоговая защита с результатами работы за год.
